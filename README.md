# 疾風ターフ

読め。賭けろ。叫べ。出馬表とパドックで予想して馬券を買い、実況つきのレースを見守る競馬ゲーム(ブラウザで遊べます)。

- 遊ぶ: https://pani1208.github.io/oya-gacha/
- ひとりで:所持金10,000円から、どこまで増やせるか
- みんなで対戦:部屋を作って4桁の合言葉を友達に送る(2〜8人)。同じレースに全員で馬券を買い、最後に一番お金を持っていた人の勝ち

通信には Supabase Realtime(公開キーのみ)を使っています。
